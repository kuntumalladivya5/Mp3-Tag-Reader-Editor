MP3 Tag Reader and Editor
📖 About the Project

The MP3 Tag Reader and Editor is an application designed to read and edit metadata stored in MP3 audio files. It enables users to view and modify information such as the song title, artist name, album name, release year, and genre.

The project provides a convenient way to organize and manage music files by updating their ID3 tags.

✨ Features
🎵 Read MP3 file metadata.
✏️ Edit song titles and artist names.
💿 Update album information.
📅 Modify the release year and genre.
💾 Save updated metadata to MP3 files.
📂 Manage music file information efficiently.
🎯 Objectives
To understand MP3 file structures and ID3 tags.
To learn how to read and modify audio metadata.
To implement file handling and data manipulation.
To develop an efficient tool for managing music information.

⚙️ How It Works
Select an MP3 File: Choose the audio file whose metadata you want to access.
Read Tags: Display the existing metadata, such as title, artist, and album.
Edit Tags: Modify the required information.
Save Changes: Update the MP3 file with the new metadata.
Verify: Read the tags again to confirm the changes.
